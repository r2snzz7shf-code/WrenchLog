# WrenchLogWrenchLog starter

A mobile-friendly car garage, maintenance log, build sheet, and expense tracker prototype.

## What works
- Add, edit, and delete vehicles
- Track maintenance, modifications, and other expenses
- Calculate total spending and record counts
- Save data in the current browser using `localStorage`
- Responsive layout for phones and desktop

## Important limitations
- This is a starter prototype, not a production-ready service.
- Data is stored only in the current browser on the current device. Clearing browser data can erase it.
- There are no user accounts, cloud sync, automated notifications, photo uploads, or verified vehicle-specific service intervals yet.
- Don't use it as the sole copy of important maintenance records.

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new repository, for example `wrenchlog`.
2. Upload `index.html` and `README.md` from this folder to the repository root.
3. In the repository, open **Settings â Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the deployment to finish. GitHub will show the site URL in the Pages section.
